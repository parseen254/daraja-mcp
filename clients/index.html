Keeping credentials out of config files#

The examples inline credentials for clarity, which is fine for sandbox and bad for production. Most clients inherit the shell environment, so prefer:

in your shell profile or a secret manager, and leave env out of the JSON.

A config file with production M-Pesa credentials is a file that eventually gets committed.
